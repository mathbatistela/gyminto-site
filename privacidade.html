Política de Privacidade

Atualizada em 20 de outubro de 2026.

Resumo

O Gyminto não tem servidor. Seus treinos ficam no seu relógio e no seu celular. Se você entrar com Google, uma cópia de segurança vai para o seu Google Drive. Ninguém mais recebe seus dados.

O que o app guarda

  • Treinos: exercícios, séries (peso, repetições, tempo, distância), horários e frequência cardíaca medida pelo relógio.
  • Rotinas, exercícios próprios (com foto, se você escolher uma), notas e preferências (tema, frequência cardíaca máxima e afins).
  • Perfil: o nome e a foto que você definir.

Esses dados ficam no armazenamento do relógio e do celular e passam entre os dois pelo Wear OS (Google Play Services), sem sair dos seus aparelhos por conta do Gyminto.

Entrar com Google (opcional)

Ao entrar, o Google compartilha com o app seu nome, e-mail e foto de perfil; eles são usados só para mostrar seu perfil no app e identificar a conta do backup.

O app pede uma única permissão do Google Drive: ver, criar e excluir os próprios dados de configuração do app (drive.appdata). Com ela, o Gyminto guarda um arquivo de backup numa pasta oculta do seu Drive, que só ele acessa. O app não vê nem altera nenhum outro arquivo do seu Drive.

O backup roda no horário que você escolher (ou quando você pedir) e serve para restaurar seus dados num celular novo.

O que o Gyminto não faz

  • Não envia dados para servidores próprios nem de terceiros.
  • Não vende, compartilha ou usa seus dados para publicidade.
  • Não usa análise de uso, rastreamento ou anúncios.

O uso de dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como apagar seus dados

  • No app: Ajustes → Conta → Sair da conta Google interrompe o backup (os dados continuam no celular).
  • Backup no Drive: no Google Drive (web), Configurações → Gerenciar apps → Gyminto → Excluir dados ocultos do app.
  • Acesso do app: myaccount.google.com/connections → Gyminto → remover acesso.
  • Dados no aparelho: desinstalar o app (ou limpar os dados dele nas configurações do Android).
